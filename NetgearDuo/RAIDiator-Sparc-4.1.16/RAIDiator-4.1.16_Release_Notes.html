RAIDiator 4.1.16 release runs on the ReadyNAS NV+, NV, Duo, 1100, X6, and 600 systems.

The simplest way to update is to use the System/Update/Remote tab in FrontView. We recommend that you update your ReadyNAS to this latest RAIDiator release to ensure your ReadyNAS is running with all the latest bug fixes and enhancements.

The following are changes since RAIDiator 4.1.15.


Bug Fixes:

  1. Fixes for Samba CVE-2017-7494.

Using the Download Link below, download and extract the new firmware to a convenient place such as your desktop.
